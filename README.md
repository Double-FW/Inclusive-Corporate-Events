# Inclusive Corporate Events

A practical checklist and reference guide for creating more accessible and inclusive corporate events for disabled attendees, presenters, and staff.

This repository brings together guidance for planning, delivering, and improving events across in-person, remote, and hybrid formats.

## Why this matters

Accessible events are not just a compliance issue—they improve participation, confidence, and quality for everyone. Good event design reduces barriers, supports better communication, and creates a more welcoming experience for all attendees.

## Repository contents

- [Corporate Event Accessibility Guide](Corporate%20Event%20Accessibility%20Guide.md)  
  A concise operational checklist covering planning, venue access, communication, staffing, catering, and post-event feedback.

- [Disabled-Attendee-Corporate-Event-Lifecycle](Disabled-Attendee-Corporate-Event-Lifecycle.md)  
  A fuller lifecycle guide that follows the attendee journey from awareness and registration through participation, feedback, and continuous improvement.

- [AGENTS.md](AGENTS.md)
  Operating guidance for AI agents supporting the planning, promotion, registration, production, delivery, and evaluation of events.

- [LICENSE](LICENSE)  
  Licensing information for this repository.

## Recommended use

Use the short checklist when you need a quick event-access review or planning prompt. Use the lifecycle guide when you want a deeper, attendee-centered view of what good accessibility looks like across the whole event journey.

When using AI to plan or deliver an event, follow [AGENTS.md](AGENTS.md) alongside both event guides. It defines human approval points, privacy safeguards, escalation rules, and checks for AI-supported work.

## Core themes

- Accessible registration and communication
- Step-free routes and inclusive venue design
- Captioning, interpreters, and communication support
- Inclusive presentation and digital content
- Quiet spaces, accessible seating, and support infrastructure
- Feedback and continuous improvement

## Contributing

This repository is intended as a reusable resource for event teams, accessibility practitioners, and organisational stakeholders. If you are adapting the guidance for a specific event type or sector, consider updating the documentation in a way that remains practical, inclusive, and evidence-based.
